# Bundled logos

Served at `/api/v1/media/logos/<file>`. Seeded universities point at them (`prisma/catalog/logos.ts`);
the seed only fills an empty logo, so a logo uploaded from the admin always wins.

Each file is a 256 px rendition from Wikimedia Commons, downloaded 2026-10-10. Logos are trademarks of
their universities and are shown only to identify them. Licences and authors as listed on Commons:
