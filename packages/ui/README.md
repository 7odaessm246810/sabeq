# @sabeq/ui — design-system components

React components for the SABEQ design system, ported from the design handoff (`bundle.css`, `bundle.js`).

- `@sabeq/ui/styles.css` — the `sb-` stylesheet (light only), inside `@layer components`.
- `Icon`, `Logo`, `LogoMark` — Phase 03. The rest of the components (Button, Input, MentorCard, …) — Phase 04.

Consumed **as source**: apps list it in `transpilePackages`. No build step.
